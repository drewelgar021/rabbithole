# RabbitHole

RabbitHole is an AI powered music recommendation app, that generates a list of recommended songs
based on a list of songs and artists that the user inputs.

## API
This project was created for a uni assignment with a provided API, so API keys are hardcoded because
I do not pay for the API and this was the easiest way to make the web app testable across different
people and devices. With that being said, this app's functionality will last for only as long as the
course API survives.
